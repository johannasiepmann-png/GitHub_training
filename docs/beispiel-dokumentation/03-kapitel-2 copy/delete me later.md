# Kapitel 2: Änderungen nachvollziehen

GitHub macht es möglich, Änderungen an Dokumenten gemeinsam zu bearbeiten und nachzuvollziehen. Jede Änderung kann beschrieben und später mit älteren Versionen verglichen werden.

Ein sinnvoller Commit enthält eine kleine, klar abgegrenzte Änderung. Eine Nachricht wie „Link zum nächsten Kapitel ergänzt“ hilft anderen Personen dabei, den Zweck der Änderung zu verstehen.

Bei der Zusammenarbeit können Vorschläge zunächst geprüft werden, bevor sie in den Hauptstand übernommen werden. Dadurch bleibt die Dokumentation übersichtlich und zuverlässig.
