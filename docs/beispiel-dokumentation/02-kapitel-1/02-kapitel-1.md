# Kapitel 1: Arbeiten mit Markdown

Markdown ist eine leicht lesbare Auszeichnungssprache. Mit ihr lassen sich Texte strukturieren, ohne dass eine spezielle Textverarbeitung notwendig ist.

Eine Überschrift beginnt mit einem oder mehreren Rautezeichen. Für eine Liste wird jede Zeile mit einem Bindestrich begonnen. So können wichtige Informationen schnell und übersichtlich dargestellt werden.

Auch Links sind einfach einzufügen. Ein relativer Link verweist auf eine Datei innerhalb des Projekts und funktioniert unabhängig davon, wo das Repository gespeichert ist.
